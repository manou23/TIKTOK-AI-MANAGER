## الإصدار الحالي

**v2.0.0** · versionCode 11

### ما يتضمنه التطبيق

**إنشاء الفيديو وتحريره**
- اختيار عدة صور وترتيب المشاهد وحذف أي صورة.
- مدد للمشهد من 3 إلى 10 ثوانٍ، وتصدير عمودي بدقة 720p أو 1080p و30 FPS.
- انتقال تلاشي متداخل بين المشاهد مع خيارات مدة الانتقال.
- نص عربي فوق الفيديو مع التحكم في الحجم والموضع.
- موسيقى خلفية وتعليق صوتي عربي محلي، مع تحكم مستقل بمستوى صوت كل منهما.
- تصدير MP4/H.264 وحفظ الفيديو داخل `Movies/MESUT TikTok`.
- التحقق من وجود الملف ومدة الفيديو ودقته قبل حفظه في المعرض.

**إدارة المشاريع**
- حفظ عدة مشاريع محلية بأسماء مختلفة.
- استعادة الصور والنصوص والصوت وإعدادات التصدير.
- حذف المشاريع المحفوظة أو استبدال مشروع بالاسم نفسه.

**ربط TikTok والنشر**
- تسجيل الدخول باستخدام TikTok OpenSDK الرسمي وPKCE والتحقق من `state`.
- خادم Cloudflare Worker لتبادل رمز التفويض وحفظ رموز TikTok مشفرة خارج APK.
- اختيار خصوصية المنشور وتعطيل التعليقات أو Duet أو Stitch قبل النشر.
- رفع الفيديو على أجزاء إلى TikTok Content Posting API ومتابعة حالة النشر، مع احتساب صحيح للجزء الأخير واختبارات لأحجام الملفات المختلفة.
- جدولة النشر على الهاتف عبر Android WorkManager مع إمكانية إلغاء المهام التي لم تبدأ.
- تحليلات أحدث 20 فيديو: المشاهدات والإعجابات والتعليقات والمشاركات.

### ما يحتاج إعداداً خارج التطبيق

ميزات إنشاء الفيديو والمشاريع تعمل محلياً. أما ربط الحساب والنشر والجدولة والتحليلات فتحتاج إلى:
1. تسجيل تطبيق في TikTok for Developers وإضافة Login Kit وContent Posting API.
2. موافقة TikTok على الصلاحيات المطلوبة، ومنها `video.publish` و`video.list`.
3. إعداد Cloudflare Worker وKV والأسرار وفق [دليل إعداد TikTok](docs/TIKTOK_API_SETUP.md)، ثم تشغيل سير عمل النشر اليدوي.
4. ضبط GitHub Secrets الخاصة بـ `TIKTOK_CLIENT_KEY` و`TIKTOK_REDIRECT_URI` و`TIKTOK_WORKER_URL`.

لا يضع التطبيق كلمة مرور TikTok أو client secret أو refresh token داخل APK. النشر العام لا يعمل قبل موافقة TikTok؛ وقد تقيد التطبيقات غير المدققة المنشورات إلى الخاص.

**ملاحظة الجدولة:** يستخدم Android WorkManager، ولذلك قد يتأخر التنفيذ قليلاً بسبب وضع توفير الطاقة أو انقطاع الشبكة أو إيقاف التطبيق قسرياً. لا نعد بتوقيت دقيق بالدقيقة.

## طريقة الاستخدام

1. افتح استوديو إنتاج الفيديو وأدخل العنوان والوصف.
2. اختر الصور، ورتب المشاهد، واضبط المدة والدقة والانتقالات.
3. أضف النص الظاهر والموسيقى أو التعليق الصوتي واضبط مستويات الصوت.
4. أنشئ الفيديو وانتظر فحص الملف وحفظه في المعرض.
5. احفظ المشروع إذا أردت العودة إليه لاحقاً.
6. بعد إعداد TikTok وخادم الربط، اربط الحساب واختر النشر المباشر أو الجدولة أو التحليلات.

## تنزيل APK

[**⬇️ افتح أحدث بناء على GitHub Actions**](https://github.com/manou23/TIKTOK-AI-MANAGER/actions/workflows/android.yml)

1. افتح أحدث تشغيل ناجح من سير العمل **Android APK**.
2. نزّل Artifact باسم `MESUT-TikTok-AI-Manager-debug`.
3. فك ضغط الملف وثبّت APK على هاتف Android 10 أو أحدث.

**تنبيه:** البناء الحالي Debug APK للتجربة، وليس إصداراً Release موقعاً بمفتاح إنتاج ثابت.
