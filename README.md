## الإصدار الحالي
**v1.3.0 — تحكم متقدم في النصوص الظاهرة داخل الفيديو**

### ما يعمل في هذا الإصدار
- اختيار عدة صور من الهاتف مع حفظ الاختيارات بين مرات فتح التطبيق.
- إعادة ترتيب المشاهد للأعلى والأسفل وحذف صورة منفردة قبل التصدير.
- إضافة نص عربي ظاهر فوق الفيديو بخلفية داكنة، مع التحكم في حجمه (صغير/متوسط/كبير) وموضعه (أعلى/وسط/أسفل).
- تحديد مدة كل مشهد: 3 أو 4 أو 5 أو 6 أو 8 أو 10 ثوانٍ.
- اختيار دقة التصدير العمودي: 1080p أو 720p.
- اختيار ملف موسيقى خلفية محلي وتكراره تلقائياً، مع إمكانية دمجه في الوقت نفسه مع التعليق الصوتي.
- كتابة تعليق صوتي عربي وتحويله إلى ملف صوت محلياً عبر محرك Android Text-to-Speech (حسب توفر الصوت العربي على الهاتف).
- استخدام التعليق الصوتي الناتج مرة واحدة دون تكراره تلقائياً، مع مزجه مع الموسيقى الخلفية.
- إدخال عنوان ووصف وهاشتاغات.
- تركيب الصور بالتتابع (4 ثوانٍ لكل صورة، 30 إطاراً/ثانية).
- تصدير الفيديو بصيغة MP4 باستخدام H.264، وإضافة ملف صوتي اختياري بصيغة AAC.
- حفظ الناتج في معرض الهاتف داخل `Movies/MESUT TikTok`.
- مشاركة الفيديو إلى TikTok أو أي تطبيق متوافق عبر قائمة المشاركة؛ يؤكد المستخدم النشر داخل TikTok.

### طريقة الاستخدام
1. افتح **استوديو إنتاج الفيديو**.
2. اكتب عنوان الفيديو والوصف، وأدخل النص الذي تريد ظهوره داخل الفيديو (اختياري).
3. اختر صورة واحدة أو عدة صور.
4. اكتب نص التعليق الصوتي إن رغبت واضغط إنشاء تعليق صوتي عربي، أو اختر ملفاً صوتياً من الهاتف.
5. استخدم أزرار ↑ و↓ لترتيب المشاهد أو زر حذف لإزالة صورة.
6. اختر مدة المشهد ودقة الفيديو.
7. أضف نصاً ظاهراً فوق الفيديو، واختر حجمه وموضعه إن رغبت.
8. اضغط **إنشاء فيديو MP4** وانتظر اكتمال التصدير.
9. اضغط **مشاركة آخر فيديو** واختر TikTok، ثم أكمل النشر داخل TikTok.

### حدود واضحة
- إنتاج الفيديو الحالي هو محرر محلي يجمع صور المستخدم وصوتاً اختيارياً؛ ليس مولداً سحابياً لمشاهد AI حتى الآن.
- لا يوجد اتصال مباشر بحساب TikTok في هذا الإصدار.
- النشر المباشر عبر Content Posting API يتطلب تطبيق TikTok for Developers، وتفعيل المنتج، وموافقة نطاق `video.publish` وتفويض المستخدم. التطبيقات غير المدققة تقيد المنشورات إلى الخاص. لذلك لا ندّعي أن النشر الآلي جاهز قبل استيفاء الموافقات.
- لا يطلب التطبيق كلمة مرور TikTok.

## البناء والتنزيل
[**⬇️ افتح صفحة تنزيل أحدث APK من GitHub Actions**](https://github.com/manou23/TIKTOK-AI-MANAGER/actions/workflows/android.yml)

يتم بناء APK تجريبي تلقائياً عند كل تحديث إلى `main`.
1. افتح تبويب **Actions**.
2. افتح أحدث تشغيل ناجح من **Android APK**.
3. نزّل Artifact باسم `MESUT-TikTok-AI-Manager-debug`.
4. فك ضغطه وثبّت APK على هاتف Android 10 أو أحدث.
