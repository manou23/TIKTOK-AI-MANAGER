## 📌 نظرة عامة

**MESUT TikTok AI Manager** تطبيق Android يساعد على تجهيز فيديوهات قصيرة وإدارة عملية نشرها على TikTok من خلال واجهات المطور الرسمية. يجمع بين محرر فيديو بسيط، وحفظ المشاريع محلياً، وربط الحساب، ورفع الفيديو ومتابعة حالة النشر، والجدولة والتحليلات.

| معلومات المشروع | التفاصيل |
|---|---|
| الإصدار الحالي | **2.0.2** |
| Android | 10 أو أحدث (minSdk 29) |
| لغة التطبيق | Kotlin |
| versionCode | 13 |
| معرّف التطبيق | com.mesut.tiktokmanager |
| الفرع الأساسي | main |

## ✨ المزايا

### 🎬 إنشاء الفيديو وتحريره
- اختيار عدة صور وترتيب المشاهد وحذف الصور غير المطلوبة.
- عرض صور مصغّرة للمشاهد ومعاينة كل مشهد والتنقل بين الصور قبل التصدير.
- تحديد مدة المشهد من 3 إلى 10 ثوانٍ.
- تصدير فيديو عمودي بدقة 720p أو 1080p وبمعدل 30 إطاراً في الثانية.
- انتقالات تلاشي متداخلة مع التحكم في مدة الانتقال.
- إضافة نص عربي فوق الفيديو والتحكم في حجمه وموضعه.
- إضافة موسيقى خلفية وتعليق صوتي عربي محلي.
- ضبط مستوى صوت الموسيقى والتعليق الصوتي كلٌّ على حدة.
- تصدير MP4 بترميز H.264 وحفظه في مجلد Movies/MESUT TikTok.
- فحص وجود الملف ومدته ودقته قبل اعتباره جاهزاً.

### 🗂️ إدارة المشاريع
- حفظ عدة مشاريع محلياً بأسماء مختلفة.
- استعادة الصور والنصوص والصوت وإعدادات التصدير.
- حذف مشروع محفوظ أو استبداله بالاسم نفسه.

### 🔗 ربط TikTok والنشر
- تسجيل الدخول من خلال TikTok OpenSDK الرسمي مع PKCE والتحقق من state.
- خادم Cloudflare Worker لتبادل رمز التفويض وحفظ رموز TikTok مشفرة خارج التطبيق.
- اختيار إعدادات الخصوصية وتعطيل التعليقات أو Duet أو Stitch قبل النشر، وفق الخيارات التي تتيحها TikTok.
- رفع الفيديو على أجزاء إلى TikTok Content Posting API.
- متابعة حالة النشر والتحقق من اكتماله.
- جدولة النشر على الهاتف باستخدام Android WorkManager مع إمكانية إلغاء المهام التي لم تبدأ.
- عرض تحليلات أحدث 20 فيديو: المشاهدات والإعجابات والتعليقات والمشاركات، بحسب البيانات التي توفرها TikTok والصلاحيات الممنوحة.

### 📸 Instagram Reels
- ربط حساب Instagram الاحترافي Business/Creator عبر Meta OAuth الرسمي.
- رفع فيديو MP4 إلى Cloudflare R2، وإنشاء Reel ومتابعة جاهزية الحاوية ثم نشره عبر Meta Graph API.
- فصل الحساب وإبقاء رموز Meta مشفرة داخل Worker/KV، لا داخل APK.
- يتطلب الإعداد مفاتيح Meta وR2 وربط حساب Instagram بصفحة Facebook، ومراجعة Meta عند الحاجة. الميزة لا تعمل قبل إعداد الخادم والصلاحيات. راجع [دليل Instagram](docs/INSTAGRAM_API_SETUP.md).

## 🛠️ التثبيت والإعداد

### المتطلبات
- هاتف Android 10 أو أحدث لتثبيت التطبيق.
- حساب TikTok Developer وتطبيق مسجل لدى TikTok لتفعيل الربط والنشر.
- Cloudflare Worker وKV لتشغيل خادم الربط الآمن.
- لنشر Instagram: تطبيق Meta Developer وحساب احترافي مرتبط بصفحة Facebook، وCloudflare R2 مع نطاق HTTPS عام للوسائط.
- صلاحيات TikTok المطلوبة وموافقة المنصة حيثما كانت مطلوبة.

### إعداد TikTok
اتبع الدليل خطوة بخطوة: **[docs/TIKTOK_API_SETUP.md](docs/TIKTOK_API_SETUP.md)**

يتضمن الدليل إعداد Login Kit وContent Posting API، وCloudflare Worker وKV، وأسرار GitHub Actions، وبناء APK مهيأ للربط.

### طريقة الاستخدام الأساسية
1. افتح استوديو إنتاج الفيديو.
2. أدخل العنوان والوصف، ثم اختر الصور ورتّب المشاهد.
3. اضبط مدة المشاهد والدقة والانتقالات.
4. أضف النص والموسيقى أو التعليق الصوتي واضبط مستويات الصوت.
5. أنشئ الفيديو وانتظر انتهاء التصدير والفحص.
6. احفظ المشروع إذا رغبت في تعديله لاحقاً.
7. بعد إكمال إعداد TikTok، اربط الحساب واختر النشر أو الجدولة أو التحليلات.
8. لاستخدام Instagram، أكمل إعداد Meta وR2 في [دليل Instagram](docs/INSTAGRAM_API_SETUP.md)، ثم اربط الحساب وانشر الفيديو كـ Reel.

## 🔐 الخصوصية والأمان

- لا يطلب التطبيق كلمة مرور TikTok ولا يحاول تسجيل الدخول بمحاكاة النقرات.
- تتم المصادقة من خلال تدفق TikTok الرسمي.
- لا ينبغي تضمين Client Secret أو مفاتيح التشفير أو رموز التحديث السرية داخل APK.
- تُحفظ رموز TikTok الحساسة في الخادم وتُشفّر قبل التخزين.
- لا تضع أسرار GitHub أو رموز الوصول في ملفات المصدر أو في Issues عامة أو في المحادثات.
- يتطلب النشر العام موافقة TikTok على التطبيق والصلاحيات. قد تقتصر التطبيقات غير المدققة على نشر خاص.
- الجدولة تعتمد على Android WorkManager؛ قد يؤخر نظام Android التنفيذ بسبب توفير الطاقة أو انقطاع الاتصال أو إيقاف التطبيق قسرياً، لذلك لا يُضمن وقت تنفيذ دقيق بالدقيقة.

## 🧱 التقنيات المستخدمة

- **Android / Kotlin** — التطبيق.
- **Jetpack Media3** — معالجة وتصدير الفيديو.
- **TikTok OpenSDK** — تسجيل الدخول الرسمي.
- **TikTok Content Posting API** — الرفع والنشر.
- **Meta Graph API** — Instagram OAuth ونشر Reels للحسابات الاحترافية.
- **Cloudflare R2** — استضافة مؤقتة لوسائط Instagram التي تجلبها Meta عبر URL عام.
- **Android WorkManager** — مهام الجدولة.
- **Cloudflare Workers + KV** — خدمات الربط وحفظ الرموز المشفرة.
- **GitHub Actions** — البناء والتحقق والنشر الآلي للخادم.
